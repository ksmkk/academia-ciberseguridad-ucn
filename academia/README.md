# Academia

La Academia de Ciberseguridad UCN es un espacio de aprendizaje práctico y colaborativo creado para aprender haciendo.

Aquí reunimos la forma en que trabajamos, nuestras normas, criterios de documentación y material común para clases y laboratorios.

No buscamos convertir cada actividad en una receta. La meta es que cada integrante pueda explicar qué observó, por qué una técnica funcionó, qué evidencia la respalda y cómo se puede reducir el riesgo.
