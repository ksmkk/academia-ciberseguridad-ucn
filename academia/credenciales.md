# Gestión de credenciales

Las credenciales que aparezcan en esta documentación deben ser exclusivamente de laboratorio y creadas para ese ejercicio.

## Qué puede publicarse

Credenciales temporales y deliberadamente compartidas para una máquina o práctica concreta.

```
usuario: student
contraseña: lab-only-2026
```

## Qué no debe publicarse

* Contraseñas institucionales o personales.
* Tokens de GitHub.
* API keys.
* Claves SSH privadas.
* Cookies o tokens de sesión.
* Credenciales de servicios cloud.
* Secretos de aplicaciones reales.

Para secretos reales se debe utilizar un gestor de credenciales. En GitBook, como máximo, se deja una referencia al lugar donde se administra el secreto.
