# Gestión de credenciales

## Permitido
Solo credenciales creadas expresamente para un laboratorio, por ejemplo:

```text
usuario: student
contraseña: lab-only-2026
```

## Prohibido
- Contraseñas institucionales
- Tokens GitHub
- API keys
- Claves SSH privadas
- Cookies de sesión
- Tokens OAuth
- Secretos personales

Para secretos reales, usar un gestor (Bitwarden, 1Password u otro) y dejar aquí una referencia al vault.
