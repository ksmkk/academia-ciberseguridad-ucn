# Cloud Security

Introducción práctica a errores frecuentes de seguridad en entornos cloud.

## Temas

* IAM y roles;
* principio de mínimo privilegio;
* almacenamiento expuesto;
* credenciales y secretos;
* configuraciones inseguras;
* rutas conceptuales de escalada de privilegios.

El foco está en aprender a leer permisos y relaciones de confianza.
