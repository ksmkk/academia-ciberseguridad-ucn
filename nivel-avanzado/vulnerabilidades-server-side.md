# Vulnerabilidades server-side

Módulo orientado a técnicas donde el servidor procesa información controlada por el usuario de formas inesperadas.

## Temas

* SSRF;
* SSTI;
* Prototype Pollution;
* Request Smuggling;
* Cache Poisoning.

Cada técnica se estudia desde su funcionamiento, condiciones necesarias, impacto, detección y mitigación.
