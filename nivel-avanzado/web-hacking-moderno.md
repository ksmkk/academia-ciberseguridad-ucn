# Web Hacking moderno

Profundizamos en vulnerabilidades web que exigen entender lógica de aplicación, control de acceso y comportamiento de APIs.

## Temas

* IDOR y Broken Access Control;
* fallos de lógica de negocio;
* APIs;
* sesiones y autorización;
* análisis con Burp Suite.

El foco está en razonar sobre el comportamiento de la aplicación, no solo en ejecutar payloads conocidos.
