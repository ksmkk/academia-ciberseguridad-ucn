# Linux para seguridad

Linux aparece constantemente en laboratorios, servidores y herramientas de ciberseguridad. En este módulo trabajamos lo necesario para movernos con comodidad antes de enfocarnos en explotación.

## Contenidos

* sistema de archivos;
* permisos y propietarios;
* procesos y servicios;
* usuarios y grupos;
* comandos de búsqueda y filtrado;
* conexiones de red;
* lectura de logs básicos.

El objetivo no es memorizar comandos, sino saber encontrar información útil cuando estamos investigando un sistema.
