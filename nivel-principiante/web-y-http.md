# Web y HTTP

Este módulo introduce cómo funciona una aplicación web antes de estudiar vulnerabilidades.

## Contenidos

* request y response;
* métodos HTTP;
* headers;
* cookies y sesiones;
* parámetros;
* códigos de estado;
* código fuente del navegador;
* rutas y subdirectorios;
* `robots.txt` y `sitemap.xml` como fuentes de información.

Entender el protocolo hace mucho más fácil reconocer comportamientos extraños después.
