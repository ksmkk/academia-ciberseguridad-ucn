# Plataformas de práctica

La práctica constante es parte central del aprendizaje.

Podemos utilizar plataformas y laboratorios como DockerLabs, PortSwigger Web Security Academy, OverTheWire, Hack The Box y TryHackMe según el nivel y el objetivo de cada clase.

La elección de una plataforma debe responder a qué queremos aprender, no solamente a completar máquinas.
